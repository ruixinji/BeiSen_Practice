# 北森测评刷题平台

> 言语理解 · 资料分析 · 图形推理 —— 共 445 道题的专项练习平台，纯前端实现，打开即用。

**在线体验（无需安装，直接开）：** https://beisen-practice.app.workbuddy.host/

---

## 功能特性

| 功能 | 说明 |
| --- | --- |
| 三大专项练习 | 言语理解与表达 40 题、资料分析 253 题、图形推理 152 题 |
| 即时判分 + 解析 | 提交后立即显示对错与解析，不必等到最后 |

| 收藏夹 | 标记重点题目，随时回顾 |

| 进度自动保存 | 作答、收藏、错题实时写入浏览器本地存储 |
| **进度备份 / 恢复** | 一键导出为 JSON 文件，换设备、清缓存后可完整恢复（见下） |

## 快速开始

环境要求：**Node.js 18+**（推荐 20/22），包管理器 npm / pnpm / yarn 均可。

```bash
# 安装依赖
npm install

# 启动开发服务器 → http://localhost:5173
npm run dev

# 构建生产版本（产物在 dist/）
npm run build

# 本地预览构建产物
npm run preview
```

> 首次进入需要先**注册一个账号**（右上角「注册」）。账号与进度只存在你自己的浏览器里，不上传服务器，随便设用户名和密码即可。

## 进度备份与恢复

浏览器数据（localStorage）在换设备、清理缓存、换浏览器时会丢失。为此项目内置了导出/导入能力：

入口：**右上角头像 → 「导出进度备份」/「从备份恢复」**

- **导出**：把当前账号的作答记录、收藏、错题打包成 `beisen-backup-<用户名>-<时间>.json` 下载到本地。
- **恢复**：选择备份文件即可导入。采用**并集合并**策略——只补进缺失的记录，不会覆盖你已有的进度，误导入也不会毁数据。
- **容错**：非 JSON 文件、其它应用的文件、版本不兼容、空记录都会给出明确的中文提示，不会静默失败。

备份模块（`src/data/backup.js`）只通过 `auth.js` 的两个读写函数存取数据，想改造成云端同步时只需替换这一个文件，UI 无需改动。

## 部署到 GitHub Pages

`vite.config.js` 中的 `base` 已设为 `/BeiSen_Practice/`，与仓库名一致，因此**直接构建即可部署到 Pages**：

```bash
npm run build
# 把 dist/ 的内容推到 gh-pages 分支即可
```

如果想部署在**根域名**或其它路径下，构建时要显式覆盖 base，否则资源路径会全部 404：

```bash
# 部署到站点根目录
npm run build -- --base=./

# 或部署到自定义子路径
npm run build -- --base=/my-path/
```

> 本项目线上的那份就是按 `--base=./` 构建的。

## 题库构成

| 专项 | 题数 | 特点 |

| 言语理解与表达 | 40 | 片段阅读、逻辑填空、语句表达 |

## 常见问题

**启动后 `localhost:5173` 打不开？**
部分 Windows 环境 `localhost` 会解析到 IPv6，而 Vite 默认监听 IPv4。改用 `http://127.0.0.1:5173/`，或启动时显式绑定：`npm run dev -- --host 127.0.0.1`。

**本地跑正常，部署后图片/样式 404？**
是 `base` 配置问题，见上面「部署到 GitHub Pages」一节。

**换电脑后进度没了？**
正常——数据存在浏览器本地。用「导出进度备份」把 JSON 文件带过去，在新机器上注册同名账号后导入即可。

**能直接背下答案应付测评吗？**
不建议，也基本不可能：这套是 2024 年流传的整理版题库，真实测评题目会轮换。它的价值在于练手感、熟悉题型和时间节奏。
